# Banned patterns — full catalog

Load this file for any prose deliverable over ~300 words, and always in
Mode 2 (edit pass). Organized by category; each entry shows the fix.

The rule throughout: banned **as default filler**. Technical or genuinely
precise uses survive (e.g. "robust standard errors", "holistic medicine"
in a healthcare context).

---

## 1. Throat-clearing openers

| Banned | Fix |
|---|---|
| "Great question" / "That's an interesting point" | Answer it |
| "I'd be happy to help with that" | Help with it |
| "Certainly!" / "Absolutely!" | Delete |
| "In today's fast-paced / ever-evolving / digital world" | Delete the sentence |
| "In the landscape/realm/world of X" | "In X" or delete |
| "Let's dive in / take a deep dive / delve into" | Delete |
| "Before we begin, it's important to understand…" | Begin |
| "When it comes to X" | "For X" or restructure |

## 2. Hedging and filler connectors

| Banned | Fix |
|---|---|
| "It's worth noting that X" | "X" |
| "It's important to note/remember/understand that X" | "X" |
| "Importantly, / Notably, / Interestingly," | Delete; if it matters, the sentence shows it |
| "essentially / basically / fundamentally / in essence" | Delete |
| "arguably" | Argue it, or drop the claim |
| "could potentially / may potentially" | "could" |
| "may or may not" | Pick one, or name the condition |
| "in many ways" | Name one way |
| "to some extent / somewhat / relatively" | Quantify or delete |
| "Moreover, / Furthermore, / Additionally," chained across paragraphs | Restructure; consecutive paragraphs should not need glue words |
| "That being said / With that in mind" | Delete |
| "needless to say" | Then don't say it |

## 3. Empty intensifiers and graders

| Banned | Fix |
|---|---|
| truly, incredibly, deeply, highly, very, really, extremely | Delete, or replace the whole phrase with a number |
| "significant / substantial" without a figure | Give the figure |
| "a wide range of / a variety of / numerous" | Count them or name the top two |
| "myriad / plethora / a host of" | Same |
| "key" stapled to every noun ("key driver, key risk, key takeaway") | Keep one per page, maximum |

## 4. AI vocabulary

Default-banned words. Replacements in parentheses where one exists; otherwise
delete or rewrite around.

- **Verbs**: delve (examine), leverage (use), utilize (use), facilitate
  (help, run), harness (use), unlock (—), foster (build, encourage),
  empower (let), elevate (improve), streamline (simplify, cut), navigate
  (handle, manage), spearhead (lead), bolster (support), underscore (show),
  showcase (show)
- **Adjectives**: robust, seamless, holistic, comprehensive, crucial,
  pivotal, vital, cutting-edge, state-of-the-art, transformative,
  game-changing, innovative (as filler), multifaceted, nuanced (as filler),
  actionable, impactful, scalable (as filler), best-in-class, world-class
- **Nouns**: landscape, ecosystem (outside biology), journey, tapestry,
  realm, synergy, paradigm, "a testament to", "the intersection of X and Y",
  "pain points", "low-hanging fruit", stakeholder-speak in general
- **Phrases**: "best practices" (name the practice), "moving forward"
  (delete), "at the end of the day" (delete), "double down" (sometimes fine
  in deal talk — judgment), "circle back", "deep dive" as a noun

## 5. Structural tics

These matter more than vocabulary — they survive synonym substitution and
are the strongest AI fingerprint.

**Rule of three.** "Fast, reliable, and scalable." AI defaults to triads.
Fix: vary — one item, two, four. If three items are genuinely the right
number, fine, but check whether the third is padding.

**"Not only X, but also Y."** Fix: "X and Y", or two sentences with the
second doing real work.

**Negative parallelism.** "It's not just a product — it's a platform." /
"This isn't about cost; it's about control." Fix: state the second half.
If the contrast genuinely earns its place, once per document maximum.

**Antithesis openers.** "While X is true, Y…" starting every other
paragraph. Fix: state Y; concede X only if a reader would actually object.

**Em-dash chains.** More than ~one em-dash per paragraph reads as AI.
Fix: periods, commas, parentheses.

**Bold-phrase-colon bullets.** "**Speed:** the system responds in…" as the
default formatting for everything. Fix: prose, or plain bullets where the
list is genuinely parallel.

**Header inflation.** H2/H3 headers on 40-word sections. Fix: prose with
strong topic sentences; headers only when a reader will navigate by them.

**Uniform sentence length.** Every sentence 18–25 words. Fix: follow a long
sentence with a short one. Like this.

**Mirror-structure paragraphs.** Every paragraph: claim, three supports,
mini-conclusion. Fix: let paragraph shape follow the argument.

## 6. Endings

| Banned | Fix |
|---|---|
| "In conclusion / In summary / To sum up / Overall / Ultimately" | Delete the paragraph; if it contains one new thought, keep only that |
| Recap paragraph restating the sections | Delete |
| "The right choice depends on your specific needs/goals/situation" | Take the position |
| "Only time will tell" | Delete |
| "Would you like me to… / Let me know if… / Feel free to…" | End when done |
| "Exciting times ahead" and variants | Delete |

## 7. Sycophancy and false validation

| Banned | Fix |
|---|---|
| "You're absolutely right" | "Correct." — or just incorporate the fix |
| "That's a great/excellent/insightful point" | Engage with the point |
| "Thanks for sharing that" | Delete |
| Apologizing more than once for the same error | Fix it once, move on |

## 8. Before / after examples

**Executive summary opener**

> Before: "In today's rapidly evolving automotive landscape, it's worth
> noting that the company has faced a myriad of challenges that have
> significantly impacted its financial performance."
>
> After: "Revenue fell 23% over 2022–2024 while the German parent absorbed
> the cash losses; the core problem was sequencing, not operations."

**Board memo paragraph**

> Before: "It's important to note that the integration is not just a
> technical challenge — it's a cultural one. Moving forward, the team
> should leverage best practices to foster alignment and unlock synergies
> across both organizations."
>
> After: "The technical integration is the easy part. The Bonneville and
> Scionzier teams have run on different incentive systems for a decade;
> merging them without first aligning bonus structures will stall the
> plan by Q3."

**Email**

> Before: "I hope this email finds you well. I wanted to reach out to
> touch base regarding our upcoming meeting. It would be great if we
> could potentially align on the key topics beforehand."
>
> After: "Three topics for Thursday: the Q2 covenant test, the Valence
> logistics question, and headcount. Anything to add?"

**LinkedIn post**

> Before: "Thrilled to share that I've embarked on an incredible journey
> at ESADE! Excited to dive deep into the world of strategy and
> innovation alongside truly inspiring classmates."
>
> After: "Started the ESADE MBA this month. After 15 years running
> turnarounds, I'm here to test which parts of that playbook survive
> contact with AI-native businesses."
